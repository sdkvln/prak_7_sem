# Оценка стоимости квартир

Система из пяти микросервисов на Python в Docker. Она собирает объявления о
продаже квартир, обучает модель цены и оценивает квартиру по её параметрам.

Данные: выборка из 50 000 объявлений (80 регионов, 2018–2021) из набора
[Russia Real Estate 2018–2021](https://huggingface.co/datasets/daniilakk/Russia_Real_Estate_2021).
Полный набор — около 5,4 млн объявлений.

## Сценарии

1. Сбор данных: батчи из CSV загружаются в хранилище.
2. Обучение модели: случайный лес или линейная регрессия, считаются метрики.
3. Оценка квартиры: модель выдаёт цену по параметрам квартиры.
4. Отчёт по модели: метрики и значимость признаков, можно скачать HTML-файлом.

## Запуск

```bash
docker compose up -d --build
```

GUI: http://localhost:8050, Swagger: http://localhost:8000/docs.
Прогон всех сценариев без браузера: `python3 scripts/demo.py`.
Остановка: `docker compose down`.

## Файлы

| Файл | Назначение |
|---|---|
| `docker-compose.yml` | запуск всех сервисов |
| `requirements.txt` | зависимости всех сервисов |
| `data/raw/russia_real_estate_sample.csv` | выборка данных |
| `scripts/demo.py` | прогон четырёх сценариев через API |
| `services/collector/` | отдаёт данные из CSV батчами и сохраняет их в Storage, пишет журнал загрузок в `logs/collector.log` |
| `services/storage/` | CRUD объявлений, база SQLite |
| `services/ml_service/` | создание, обучение, применение и описание моделей, модели хранятся файлами |
| `services/web_master/` | единая точка входа: API сценариев и состояние сервисов |
| `services/visualization/` | веб-страница для запуска сценариев и скачивания отчёта |

В каждом сервисе есть:

| Файл | Назначение |
|---|---|
| `Dockerfile` | сборка контейнера |
| `config.yaml` | порт, адреса других сервисов, пути и параметры |
| `requirements.txt` | зависимости сервиса |
| `app/main.py` | код сервиса |

Шаблоны страницы и отчёта лежат в `visualization/app/templates/`, скрипт страницы — в `visualization/app/static/app.js`.
